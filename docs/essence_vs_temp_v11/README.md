# Essence vs. Temperature v11

This is the within-participant pilot version of the Essence vs. Temperature study.

## Design

- Every participant rates all eight animals: rhinoceros, beaver, tiger, porcupine, monkey, squirrel, lemur, and otter.
- Each participant receives exactly four purpose statements and four temperature statements.
- The animals assigned to each construct and the presentation order are deterministically randomized from the participant's Prolific identifiers. Reopening the same launch returns the same assignment.
- The order of the two final general questions is also randomized.
- Every participant answers both general questions:
  - whether each kind of animal has a purpose;
  - whether each kind of animal has a temperature.

## Explanation Lab Study Console setup

Register this as a study with exactly one condition:

- Condition label: `Mixed within-participant`
- Condition code: `mixed`

Do not create separate `purpose` and `temperature` conditions. Those constructs are assigned inside the experiment, four trials each.

Use these demographic field names when registering the study:

```text
sex, age, race
```

The experiment version is `essence_vs_temp_v11.0.0`. The data schema version is `7.0.0`.

## Local preview

Serve the entire folder from a local web server and open:

```text
http://localhost:PORT/?condition=mixed&debug=1
```

Opening `index.html` directly also runs in local-preview mode, but a local web server more closely matches GitHub Pages.

## Export fields

Target rating rows use:

- `trial_role: response`
- `measure: purpose_rating` or `temperature_rating`
- `item_id`: the animal name
- `condition` and `construct`: the trial-level construct
- `study_condition: mixed`

The two general questions use `all_animals_purpose` and `all_animals_temperature` as stable measures. Demographic rows are tagged `trial_role: demographic` and expose the stable fields `sex`, `age`, and `race`, allowing the console to keep them out of `responses.csv` and put them in `demographics.csv`.

## Hosting

Upload the complete `essence_vs_temp_v11` folder to GitHub Pages. Do not omit the `assets`, `css`, or `js` directories. In Prolific, use the single production link generated by the Explanation Lab Study Console.
